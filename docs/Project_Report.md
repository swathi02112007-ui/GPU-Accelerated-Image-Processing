
# CUDA-Accelerated Image Processing and Performance Analysis Using GPU Computing

## 1. Abstract

This project focuses on accelerating image-processing operations using NVIDIA CUDA and GPU computing. Three image-processing algorithms, namely Grayscale Conversion, Gaussian Blur and Sobel Edge Detection, are implemented using CPU and GPU approaches.

The project evaluates the performance of these implementations using four different image resolutions: 512x512, 1024x1024, 2048x2048 and 4096x4096.

The outputs generated by the CPU and GPU implementations are compared to verify correctness. Execution times are measured to analyse the performance benefits of GPU parallel processing.

## 2. Introduction

Image processing involves performing operations on digital images to improve their quality or extract useful information.

Traditional CPU-based image processing executes operations using a limited number of processing cores. GPU computing provides parallel execution capabilities, allowing multiple image pixels to be processed simultaneously.

NVIDIA CUDA is used in this project to implement parallel image-processing operations.

## 3. Problem Statement

Processing large images using traditional CPU-based methods can require significant execution time, particularly for computationally intensive operations.

This project addresses the problem by implementing image-processing algorithms using CUDA and comparing their execution performance with CPU implementations.

## 6. Methodology

The project follows these steps:

1. Generate and prepare input images.
2. Load image data into the program.
3. Execute the CPU implementation.
4. Allocate GPU memory and copy input data.
5. Launch the CUDA kernel.
6. Copy the GPU output back to the host.
7. Compare CPU and GPU results.
8. Measure execution time and calculate speedup.
9. Save processed images and performance measurements.

CUDA uses a two-dimensional grid and blocks of 16x16 threads. Each thread processes an individual image pixel.

## 7. Algorithms Implemented

### 7.1 Grayscale Conversion

Grayscale conversion transforms a colour image into shades of grey.

The weighted intensity is calculated using:

Gray = (299R + 587G + 114B) / 1000

The resulting intensity is assigned to all three colour channels.

### 7.2 Gaussian Blur

Gaussian Blur smooths an image by applying a 3x3 Gaussian filter.

The filter weights are:

    1  2  1
    2  4  2
    1  2  1

The weighted pixel sum is divided by 16 to calculate the output pixel value.

### 7.3 Sobel Edge Detection

Sobel Edge Detection identifies boundaries by calculating changes in pixel intensity.

Horizontal mask (Gx):

    -1  0  1
    -2  0  2
    -1  0  1

Vertical mask (Gy):

    -1 -2 -1
     0  0  0
     1  2  1

The edge magnitude is calculated using:

Magnitude = min(|Gx| + |Gy|, 255)

The output highlights image boundaries using grayscale intensity values.

## 8. Experimental Setup

The programs were tested using four image resolutions:

- 512x512
- 1024x1024
- 2048x2048
- 4096x4096

Each algorithm has a CPU implementation and a CUDA GPU implementation.

The GPU kernel execution time is measured using CUDA events.

Speedup is calculated as:

Speedup = CPU Execution Time / GPU Kernel Execution Time

Note: The speedup values compare CPU processing time with GPU kernel-only time. GPU memory allocation and host-device data transfers are excluded.

## 10. Output Validation

All three algorithms were tested using four image resolutions.

The CPU and GPU outputs were compared pixel by pixel.

All 12 validation tests passed successfully.

The processed images were saved in their respective output directories:

- output/grayscale/
- output/blurred/
- output/edges/

## 11. Performance Analysis

The experimental results demonstrate that GPU kernel execution was faster than CPU processing for the tested workloads.

Grayscale Conversion showed increasing measured speedup as image resolution increased.

Gaussian Blur recorded the highest measured kernel speedup in the combined experiment, reaching approximately 957.14x for the 4096x4096 image.

Sobel Edge Detection also demonstrated significant measured speedup across the tested image sizes.

These results demonstrate the potential of GPU parallel processing for image-processing workloads. However, the measurements represent kernel-only comparisons rather than complete application execution times.

## 12. Challenges and Solutions

### Challenge 1: CPU and GPU output differences

Floating-point calculations can produce small differences between CPU and GPU results.

Solution: Matching integer-based grayscale calculations were used to achieve exact output validation.

### Challenge 2: CUDA compilation

CUDA programs require correct compiler configuration and GPU support.

Solution: The programs were compiled using NVCC in Google Colab with an NVIDIA GPU runtime.

### Challenge 3: Processing large images

Larger images require more memory and processing operations.

Solution: The image-processing programs were tested using multiple image resolutions.

### Challenge 4: Performance measurement

CPU and GPU execution times need separate measurements.

Solution: CPU execution was measured using C++ timing utilities, while CUDA events were used to measure GPU kernel execution.

The performance measurements demonstrate the benefits of parallel processing for the tested image-processing operations.
