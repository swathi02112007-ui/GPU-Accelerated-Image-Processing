
# CUDA-Accelerated Image Processing and Performance Analysis

## 1. Project Overview

This project demonstrates GPU-accelerated image processing using NVIDIA CUDA.

It implements three image-processing algorithms using both CPU and GPU:
1. Grayscale Conversion
2. Gaussian Blur
3. Sobel Edge Detection

The project compares CPU execution time with GPU kernel execution time to study the performance benefits of parallel computing.

## 2. Project Objectives

- Implement image-processing algorithms using CUDA.
- Compare CPU and GPU implementations.
- Understand parallel execution using CUDA threads and blocks.
- Validate GPU results against CPU reference outputs.
- Measure execution time and calculate kernel speedup.
- Study performance across different image resolutions.

## 4. Image Processing Algorithms

### A. Grayscale Conversion

Converts a colour image into grayscale by calculating the weighted intensity of the red, green and blue channels.

### B. Gaussian Blur

Applies a 3x3 Gaussian filter to smooth an image and reduce fine details.

Gaussian filter:

    1  2  1
    2  4  2
    1  2  1

The weighted sum is divided by 16.

### C. Sobel Edge Detection

Detects image boundaries using horizontal and vertical Sobel masks.

The edge magnitude is calculated using:

    Magnitude = min(|Gx| + |Gy|, 255)

The resulting image highlights edges in grayscale.

## 7. Compilation

Navigate to the project directory and compile all programs:

    make clean
    make

This generates three executables:

- grayscale
- gaussian_blur
- sobel_edge

## 8. Individual Execution

Grayscale:

    ./grayscale input/image_512.ppm output/grayscale/image_512_gray.ppm

Gaussian Blur:

    ./gaussian_blur input/image_512.ppm output/blurred/image_512_blur.ppm

Sobel Edge Detection:

    ./sobel_edge input/image_512.ppm output/edges/image_512_edges.ppm

Each program accepts an input image path and an output image path.

## 9. Complete Project Execution

To execute all three algorithms on all four image sizes:

    chmod +x run_all.sh
    ./run_all.sh

The script processes images of:

- 512 x 512
- 1024 x 1024
- 2048 x 2048
- 4096 x 4096

## 10. Performance Analysis

The following measurements were obtained during a combined execution on the NVIDIA Tesla T4 GPU.

| Image Size | Algorithm | CPU Time (ms) | GPU Kernel Time (ms) | Speedup |
|---|---|---:|---:|---:|
| 512 x 512 | Grayscale | 1.021 | 0.079 | 12.95x |
| 512 x 512 | Gaussian Blur | 18.375 | 0.088 | 209.19x |
| 512 x 512 | Sobel | 8.090 | 0.111 | 72.86x |
| 1024 x 1024 | Grayscale | 3.822 | 0.077 | 49.78x |
| 1024 x 1024 | Gaussian Blur | 72.829 | 0.164 | 443.82x |
| 1024 x 1024 | Sobel | 21.696 | 0.185 | 117.12x |
| 2048 x 2048 | Grayscale | 16.835 | 0.209 | 80.66x |
| 2048 x 2048 | Gaussian Blur | 289.745 | 0.365 | 794.12x |
| 2048 x 2048 | Sobel | 82.711 | 0.319 | 259.46x |
| 4096 x 4096 | Grayscale | 62.852 | 0.691 | 91.02x |
| 4096 x 4096 | Gaussian Blur | 2199.810 | 2.298 | 957.14x |
| 4096 x 4096 | Sobel | 382.187 | 1.792 | 213.23x |

Note: Speedup is calculated using CPU processing time divided by GPU kernel execution time. GPU memory allocation and host-to-device/device-to-host transfers are excluded. These are single-run measurements, not averaged benchmark results.

## 13. Conclusion

This project demonstrates how CUDA parallel computing can accelerate image-processing operations.

Grayscale Conversion, Gaussian Blur and Sobel Edge Detection were implemented using CPU and GPU approaches.

Testing across four image resolutions showed successful output validation and significant measured kernel speedups.

The project provides practical experience with CUDA kernels, thread and block organization, image processing, performance measurement and GPU computing.
